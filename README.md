# 🎓 CodeVista Academy

**Learn Skills. Build Your Future.**

A modern, animated educational website built with HTML & CSS — an illustrative course guide for CodeVista Academy covering web development, data, marketing, design, AI, and computer essentials.

🔗 **Author:** [ThechillBoy](https://github.com/ThechillBoy)

---

## 📖 Overview

CodeVista Academy is a static, multi-page website that presents a course catalog of diploma and certificate programs. The homepage acts as a single-page hub with a course catalog organized into five areas, a gallery, a learning guide, and admissions information — each course card links to its own detail page.

---

## ✨ Key Features

- 🧭 Sticky site header with a keyboard-accessible mobile menu built from the native `<details>/<summary>` elements (no JavaScript)
- 🗂️ Course catalog grouped into five categories: Programming & Web, Data & Productivity, Design & Media, Business & Marketing, and Computer Essentials
- 📄 Dedicated detail page for each of the 21 courses (9 diplomas + 12 certificates)
- 🎞️ CSS transitions & transform-based hover effects on cards, buttons, and decorative elements
- ♿ Accessibility-first markup: skip link, ARIA labels, alt text, and `prefers-reduced-motion` support
- 🖨️ Print-friendly styles via a dedicated `@media print` stylesheet
- 📱 Responsive layout with breakpoints for large desktop, tablet, and mobile widths
